## `03` · FEATURED PROJECTS

### 🔴 REAL-TIME FRAUD DETECTION SYSTEM

**PySpark · Apache Kafka · Spark Structured Streaming · Flask · Docker Compose**

A real-time financial transaction monitoring system built around a complete streaming architecture.

The system ingests transactions through **Kafka**, processes them using **Spark Structured Streaming**, performs window-based feature engineering and ML inference, then exposes fraud alerts through a live Flask dashboard.

**Highlights**

* Real-time Kafka ingestion
* Spark Structured Streaming
* Window-based feature engineering
* PySpark MLlib inference
* Live fraud monitoring dashboard
* Fully containerized with Docker Compose

`STREAMING` `MLOPS` `PYSPARK` `KAFKA` `REAL-TIME ML`

---

### 🎵 ARABIC MUSIC GENRE RECOGNITION

**TensorFlow · Keras · Librosa · CNN · MFCC**

A CNN-based deep learning system for classifying **Arabic music genres from raw audio**.

The pipeline extracts **Mel-frequency cepstral coefficients (MFCCs)**, segments variable-length audio into manageable windows, and aggregates predictions across segments to produce a more robust final classification.

**Highlights**

* MFCC feature extraction
* CNN-based classification
* Variable-length audio handling
* Audio segmentation
* Confidence-based prediction aggregation
* Batch normalization for regularization

`DEEP LEARNING` `AUDIO PROCESSING` `CNN` `SIGNAL PROCESSING`
